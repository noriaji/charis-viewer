# Security Policy

[日本語は下にあります](#セキュリティポリシー)

## Reporting a problem

If you find a security problem in Charis Viewer (for example a way to run
code, read files, or send data that the viewer should not), please write to
**charisviewer@gmail.com**, or, if you have a GitHub account, use "Report a
vulnerability" on this repository's Security tab (it is private). GitHub
Issues are turned off, so please do not use public places for the first
report.

Please include:

- the version (the title screen or Help > About Charis Viewer shows it, for example
  "0.1.0 alpha 2"),
- what you did, and what happened,
- if you can, how to repeat it.

Please do not send passwords, keys, or other people's private data. If a
report needs a file with such data, say so and we will find another way.

Please give us time to fix a problem before you write about it in public.

## Which versions

Only the newest release gets fixes. The viewer is an alpha (a test release).

# セキュリティポリシー

## 問題を見つけたら

Charis Viewer に安全上の問題（意図しないコードの実行、ファイルの読み取り、送って
はいけないデータの送信など）を見つけたら、**charisviewer@gmail.com** へ知らせて
ください。GitHub のアカウントがあれば、このリポジトリの Security タブの
「Report a vulnerability」からも送れます（非公開です）。Issues は使っていない
ので、最初の報告は公開の場所に書かないでください。

書いてほしいこと:

- 版（タイトル画面か ヘルプ > Charis Viewer について で見られます。例: 「0.1.0 alpha 2」）
- 何をして、何が起きたか
- 可能なら、再現の手順

パスワードや鍵、他の人の個人的なデータは送らないでください。報告にそういう
データを含むファイルが必要な時は、その旨だけ書いてください。別の方法を相談
します。

直すまでの間は、公開の場に書くのを待っていただけると助かります。

## 対象の版

修正するのは最新のリリースだけです。このビューワはアルファ版（試験版）です。
