特長

① 多機能な撮影ツール画質・空と水・光と色・カメラ・アバターの設定を、検索・お気に入り・「比べる」・プリセット付きで 1 か所に。ピント固定、構図ガイド、光芒やグレア、世界を止めて何度も試す、といった写真づくりの道具がそろっています。
② 動画撮影に便利なツールドリー・ズーム・回り込みを自動で撮るカメラワーク、複数の点を滑らかに巡る演出（手振れ・タイムライン・連番撮影）、WASD とマウスで飛ぶフライカム、カメラ位置の記憶にも対応。
③ MCP 対応AI アシスタントから、ポーザーの操作や撮影ツールの設定、インベントリ検索ができます。
④ 直感的に作れるポーザー関節を直接つかんで動かす IK ドラッグで、アバターのポーズを自分の画面の中で作れます。手の形は「簡単」タブのスライダーで。保存・読み込み、BVH への書き出しにも対応。

そのほか

  • 表示が重い場所でも、見えている物から先に読み込み（画面内が灰色のまま残りにくい）
  • テクスチャの GPU 圧縮（BC7）で、ビデオメモリを約 4 分の 1 に
  • 2 回目以降の起動が速い。テレポート後は近くの物から読み込み
  • グラフィック以外は、公式ビューワの更新を取り込む方針

動作環境

  • Windows 10／11（64 ビット）
  • Vulkan 1.3 に対応した GPU とドライバー（目安: NVIDIA GTX 10 番台以降、AMD RX 400 番台以降）
  • 現在は alpha 版です。不具合があるかもしれません。
