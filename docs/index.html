特長

画面に見えている物から読み込みビデオメモリが足りない混んだ場所でも、近くの物 → 画面内 → 画面の外の順。見えている所が灰色のまま残りにくくなります。
混んだ場所で重くなりにくい影・反射・半透明の描画を見直し、人の多いイベントや描画距離の長い場所でも滑らかに動きます。
テクスチャの省メモリGPU 圧縮（BC7）で、ビデオメモリの使用量を約 4 分の 1 に。ぼやけやメモリあふれを防ぎます。
撮影ツール光芒・影・空と水面の調整など、写真を撮るための機能をまとめています。
起動・テレポートが速い2 回目以降の起動を短縮。到着後は近くの物から先に読み込みます。
複数起動でも快適2 つ以上同時に動かしても、操作中の方を優先。キャッシュや設定も壊れにくくしています。

動作環境

  • Windows 10／11（64 ビット）
  • Vulkan 1.3 に対応した GPU とドライバー（目安: NVIDIA GTX 10 番台以降、AMD RX 400 番台以降）
  • 現在は alpha 版です。不具合があるかもしれません。
