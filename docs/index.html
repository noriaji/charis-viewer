特長

Vulkan 描画公式の OpenGL の代わりに Vulkan で描画。混んだ場所・描画距離が長い場所で、公式より滑らかです。
画面内を最優先で読み込みビデオメモリが足りなくても、見えている物から先に読み込み。画面内が灰色のまま残りにくくなります。
テクスチャの省メモリGPU 圧縮（BC7）と自作の高速 JPEG2000 デコーダで、メモリと待ち時間を減らします。
撮影ツール光芒・影・空と水面の調整など、写真を撮るための機能をまとめています。
起動・テレポートが速い変換済みシェーダーを保存し、到着後は近くの物から読み込みます。
公式に追従グラフィック以外は公式の更新を取り込む方針です。

動作環境

  • Windows 10／11（64 ビット）
  • Vulkan 1.3 に対応した GPU とドライバー（目安: NVIDIA GTX 10 番台以降、AMD RX 400 番台以降）
  • 現在は alpha 版です。不具合があるかもしれません。
