# Charis Viewer's UI tokens: the one table of colours, sizes and fonts (research/239 (12), branch ui-skin).
#
# Everything below is made from this file by make_ui_tokens.py (next to it); nothing made is edited by hand:
#   pstokens.h, pstokens.cpp           the C++ values (plus::psui::style::NAME; psstyle.h includes them)
#   skins/charis/colors.xml            every colour as Ps<Name> for the XUI windows, and the official colour
#                                      names the Charis look changes (the "official" / "palette" lines)
#   skins/charis/textures/textures.xml and skins/charis/textures/charis/*.png
#                                      the window frame, buttons, tooltips, toasts and scroll bars, drawn
#                                      from these values (make_ui_tokens.py says which token each part uses)
# After a change: python -I make_ui_tokens.py   (tools/predeliver.py (u) fails while the made files differ)
#
# Lines
#   [section]                        a heading of the C++ table
#   NAME  color  #rrggbb[/alpha]     a colour; its colors.xml name is Ps + NAME in CamelCase (PANEL_BG -> PsPanelBg)
#   NAME  color  =OTHER[/alpha]      the colour of another token (the same, or with another opacity)
#   NAME  f32|s32  number | =OTHER   a size, for the C++ side only
#   NAME  font  Huge|Large|Medium|Small [bold]   one of fonts.xml's official sizes
#   official  OfficialName  =TOKEN[/alpha]   the official colour name gets the token's colour (that name only)
#   palette   OfficialName  =TOKEN[/alpha]   the same, and the official names that refer to it follow
#                                            (colors.xml resolves references while it reads each file)
#   keep      OfficialName|Prefix*           stays as the official skin has it even when a palette line would
#                                            change it (the colour picker's swatches, the text fields ...)
# Text after '#' (with a space before it) is a note; a token's note goes into pstokens.h.
#
# Sizes are UI pixels of a 1080 pixel high window. The colours of research/221 are those of the target picture
# (research/photoscreen-design-target-2026-10-30.webp); "not in the picture, in its style" marks the others.
