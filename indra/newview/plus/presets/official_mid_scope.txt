# Charis の設定の分類（fix-round108・109、research/151 §7・162。research/183 で公式の画質 7 段に移した）
#
# settings_plus.xml の全部の設定と、Charis が公式の settings.xml に足した／既定を変えた設定を、ここで分類する。
# tools/predeliver.py の (c) が次を確かめる（NG）:
#   - settings_plus.xml の設定が全部ここに 1 行ずつある（新しい設定を足したら、ここにも足す）
#   - render の設定（official render の行も）は、featuretable.txt の list all と 7 段（Low, LowMid, Mid, MidHigh,
#     High, HighUltra, Ultra）の全部に行がある（research/183: 段を動かした時に前の段の値が残らない。新しい render の
#     設定を足したら、all に上限、7 段に値を足す。MidHigh は「オフ／公式の動作」の値）。数値の型（Boolean / S32 /
#     U32 / F32）で Persist 1、all の値 ≧ 各段の値
#   - taste（好み）の設定は featuretable.txt の Charis の行（<plus> の中）に無い（段を動かしても変えない）
#   - sub の設定の主スイッチ（3 列目）は render か taste か公式の設定（transient の主スイッチは Persist 0）
#   - featuretable.txt の Charis の行（Plus* と RenderOITMode）は、どれもここで render か sub
#   - 公式の settings.xml / settings_per_account.xml に Charis が足した設定・既定を変えた設定（最新の公式リリースの
#     タグとの差）が、ここに official として載っている
#
# 分類（1 列目）:
#   render    描画・毎フレームの処理・計測に効く Charis の機能。画質の段（featuretable.txt）が値を決める。
#             MidHigh（公式との比較の段）では「オフ／公式の動作」（値は research/183 §2.1）
#   taste     描画に効くが好みの物（ルック・天気・レンズフレア・影の柔らかさ・星など）。段は触らない
#   sub       render / taste の機能の細かい値。主スイッチ（3 列目）がオフなら効かない
#   backend   Charis の速さの仕組み（Vulkan のバックエンド、変換スレッド、DGC、テクスチャの読み込み）。
#             見た目を変えない。比べたいのはこれなので、段に入れない
#   transient 保存されない状態（起動時はいつもオフ）。段に入れられない
#   snapshot  スナップショットを撮る時だけ効く（フレームの計測には効かない）
#   ui        UI・操作・通信の便利機能。描画に効かない（窓を開いた時の UI の描画だけ）
#   diag      計測・診断・開発用
#   marker    廃止したプリセットのファイルの印（ログイン時に消す・1 回だけの移行に読む）
#   official  （2 列目が分類）公式の設定ファイルにある設定。4 列目以降は説明
#
